What to know before reading this board

It is measured in points, not percent. These are spreads, so the number moves and not just the price. Points of line movement is the honest unit, and it is why this figure is never averaged into the site-wide CLV.

The entry rule is provisional. A game qualifies when its spread has moved by 1.5 points or by 15% of the opening number, whichever is larger. That threshold was set by judgement when the season started. It has not been tested against results yet, and this board is how it gets tested.

It covers the games the odds feed prices, not every game played. That is most of a Division I night but not all of it. The first two picks, on 2 and 3 November, came from a much shorter list of games, because the screener was not yet asking the feed for the full board.

The log records one pick per game. The screener runs twice a day, and only the first qualifying run for a game is written here. A later run that would have picked the other side does not appear.

The close is the last number captured before tip-off. A pick with no number captured before the start shows a dash, not an estimate.
